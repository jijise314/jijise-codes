# 삽입 정렬과 쉘 정렬의 성능 비교

같은 무작위 데이터에 대해 삽입 정렬, 쉘 정렬(기본 간격), 쉘 정렬(Knuth 간격)을 수행하고 데이터 값 사이의 비교 횟수를 측정했다.

- 데이터 크기: n = 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000
- 간격 수열 (n = 16,000 기준)
  - 기본 간격: 8000, 4000, 2000, ..., 3, 1 (13단계)
  - Knuth 수열: 9841, 3280, 1093, 364, 121, 40, 13, 4, 1 (9단계)

## 1. 실험 결과

| n | 삽입 정렬 | 쉘 (기본) | 쉘 (Knuth) |
|---:|---:|---:|---:|
| 1,000 | 251,429 | 15,559 | 13,416 |
| 2,000 | 995,550 | 37,093 | 35,578 |
| 4,000 | 4,064,497 | 83,160 | 76,033 |
| 8,000 | 16,103,339 | 202,171 | 181,466 |
| 16,000 | 63,664,675 | 492,345 | 411,678 |
| 20,000 | 99,670,628 | 608,679 | 579,838 |

모든 정렬 결과가 오름차순임을 확인했다. 난수에 따른 편차를 줄이기 위해 크기마다 30회 반복한 평균도 측정했으며, 아래 분석은 그 평균값을 기준으로 한다.

## 2. 데이터 크기 증가에 따른 비교 횟수 변화

| n 변화 | 삽입 정렬 | 쉘 (기본) | 쉘 (Knuth) |
|---|---:|---:|---:|
| 1,000 → 2,000 | ×3.97 | ×2.37 | ×2.36 |
| 4,000 → 8,000 | ×3.98 | ×2.39 | ×2.33 |
| 8,000 → 16,000 | ×4.01 | ×2.38 | ×2.31 |

- **삽입 정렬**은 n이 2배가 되면 비교 횟수가 4배가 되어 **O(n²)** 으로 증가한다. 비교 한 번에 원소를 한 칸만 옮기므로, 비교 횟수가 무작위 배열의 역순 쌍 개수(약 n²/4)와 같아진다. 실제로 n = 16,000에서 평균 64,085,132회로 n²/4 = 64,000,000과 거의 같았다.
- **쉘 정렬**은 n이 2배가 될 때 약 2.3~2.4배만 늘어 대략 **n^1.25** 에 비례한다.

## 3. 삽입 정렬과 쉘 정렬의 성능 차이

삽입 정렬은 Knuth 쉘 정렬보다 n = 1,000에서 18배, n = 20,000에서 182배 더 많이 비교했다. 증가 차수가 다르므로 데이터가 클수록 차이가 커진다.

쉘 정렬이 빠른 이유는 큰 간격으로 원소를 **한 번에 멀리 옮기기** 때문이다. 앞 단계들이 배열을 거의 정렬된 상태로 만들어 두므로, 마지막 간격 1 단계(사실상 삽입 정렬)는 n = 16,000에서 **원소당 2.78회**만 비교했다. 무작위 배열에 삽입 정렬을 하면 원소당 약 4,000회(n/4)가 필요한 것과 비교된다.

## 4. 기본 간격과 Knuth 수열의 성능 차이

| n | 1,000 | 2,000 | 4,000 | 8,000 | 16,000 | 20,000 |
|---|---:|---:|---:|---:|---:|---:|
| Knuth 절감률 | 7.3% | 7.7% | 10.1% | 12.4% | 14.8% | 10.6% |

Knuth 수열은 모든 크기에서 기본 간격보다 적게 비교했고, 대체로 n이 클수록 차이가 커졌다. n = 20,000에서 절감률이 줄어든 것은 기본 간격 수열의 모양이 n에 따라 달라지기 때문이다 (5절 참고).

n = 16,000의 간격별 비교 횟수를 보면, 기본 간격은 8000부터 125까지 7단계를 거친 뒤 간격 62 단계에서 **원소당 5.64회**로 비교가 갑자기 늘었다. 앞 단계들이 배열을 충분히 정리하지 못했다는 뜻이다. 또 기본 간격은 절반씩 줄어 단계가 13개로 Knuth(9개)보다 많아, 단계마다 드는 기본 비교 비용도 더 쌓인다.

## 5. 간격 수열이 성능에 영향을 미치는 이유

간격 h로 정렬하면 h칸씩 떨어진 원소끼리만 비교된다. 따라서 **각 단계가 이전 단계에서 비교되지 않은 원소들을 얼마나 새로 섞어 주는가**가 성능을 좌우한다.

- **기본 간격**: 간격이 정확히 절반이 되면(예: 4000 → 2000) 이미 정렬된 두 묶음을 합치기만 할 뿐이고, 서로 다른 묶음에 있던 원소는 간격이 홀수가 될 때까지 비교되지 않는다. n = 16,000 = 125 × 2⁷ 에서는 이런 단계가 7개라서 간격 62에서 밀린 작업이 몰렸고, n = 20,000 = 625 × 2⁵ 에서는 4개뿐이라 약점이 덜 드러났다.
- **Knuth 수열**: h(k+1) = 3h(k) + 1 이므로 이웃한 두 간격이 항상 **서로소**다. 매 단계 새로운 원소 쌍이 비교되어 앞 단계의 효과가 낭비되지 않는다.

이 차이는 최악의 입력에서 극단적으로 드러난다. n = 16,384(2의 거듭제곱)에서 짝수 위치에 큰 값, 홀수 위치에 작은 값을 넣고 실험했다.

| 정렬 | 비교 횟수 |
|---|---:|
| 삽입 정렬 | 66,924,939 |
| 쉘 (기본) | 26,488,129 |
| 쉘 (Knuth) | 413,353 |

기본 간격은 간격 1 전까지 모든 간격이 짝수라 짝수·홀수 위치가 전혀 섞이지 않았고, 마지막 단계 하나에서만 약 2,560만 회를 비교해 **O(n²)** 수준으로 느려졌다. Knuth 수열은 무작위 데이터와 비슷한 수준을 유지했다.

## 6. 결론

1. 삽입 정렬은 O(n²)로 증가하며, 데이터가 클수록 쉘 정렬과의 차이가 급격히 커진다.
2. 쉘 정렬은 큰 간격으로 배열을 미리 정리해 두어 비교 횟수를 약 n^1.25 수준으로 줄인다.
3. Knuth 수열은 이웃한 간격이 서로소라서 매 단계 원소가 잘 섞이므로 기본 간격보다 7~15% 적게 비교하고, 최악의 경우에도 성능이 크게 나빠지지 않는다.
