# 인접 행렬과 인접 리스트의 성능 비교

정점 100개의 그래프를 희소(간선 100개)와 밀집(간선 4,000개) 두 가지로 무작위 생성하고, 같은 그래프를 인접 행렬과 인접 리스트로 표현해 메모리와 비교 횟수를 측정했다.

## 측정 기준

- **메모리** : 행렬 = `int[100][100]` + 관리 필드, 리스트 = 헤드 포인터 100개 + 관리 필드 + 노드(16B) × 2E
- **비교 횟수** : 자료구조의 원소를 확인한 횟수

| 연산 | 인접 행렬 | 인접 리스트 |
|---|---|---|
| 삽입 | `adj[u][v]` 1회 확인 | 중복 확인을 위해 u의 리스트 전체 탐색 |
| 삭제 | `adj[u][v]` 1회 확인 | u 리스트에서 v + v 리스트에서 u 탐색 |
| 연결 여부 | `adj[u][v]` 1회 확인 | u 리스트에서 v를 찾을 때까지 탐색 |
| 인접 정점 | u행 100칸 확인 | u의 리스트 노드 수만큼 |

## 실험 결과

| 경우 | 메모리 | 삽입 | 삭제 | 연결 여부 | 인접 정점 |
|---|---:|---:|---:|---:|---:|
| Case 1 희소 - 행렬 | 40,008 B | 1 | 1 | 1 | 100 |
| Case 2 희소 - 리스트 | 4,016 B | 3 | 2 | 1 | 1 |
| Case 3 밀집 - 행렬 | 40,008 B | 1 | 1 | 1 | 100 |
| Case 4 밀집 - 리스트 | 128,816 B | 81 | 99 | 84 | 70 |

무작위로 고른 한 번의 결과는 운에 좌우되므로, 가능한 모든 대상에 대한 평균도 계산했다.

| 경우 | 삽입 | 삭제 | 연결 여부 | 인접 정점 |
|---|---:|---:|---:|---:|
| 희소 - 행렬 | 1.00 | 1.00 | 1.00 | 100.00 |
| 희소 - 리스트 | 1.97 | 4.22 | 1.98 | 2.00 |
| 밀집 - 행렬 | 1.00 | 1.00 | 1.00 | 100.00 |
| 밀집 - 리스트 | 79.24 | 81.18 | 48.01 | 80.00 |

## 분석

핵심은 **평균 차수**(= 2E / V)이다. 희소 그래프는 2, 밀집 그래프는 80이다. 인접 리스트의 비용은 리스트 길이(차수)에 비례하고, 인접 행렬의 비용은 그래프 밀도와 관계없이 일정하다.

### 희소 그래프

- **메모리** : 리스트가 4,016B로 행렬(40,008B)의 약 1/10이다. 행렬은 10,000칸 중 98%가 0인 낭비 공간이다.
- **삽입·삭제·연결 여부** : 행렬 1회, 리스트 평균 2~4회로 차이가 작다. 리스트 길이가 평균 2뿐이기 때문이다.
- **인접 정점** : 행렬은 이웃이 1개뿐이어도 100칸을 모두 확인한다. 리스트는 평균 2회로 약 50배 적다.
- **결론** : 인접 리스트가 유리하다.

### 밀집 그래프

- **메모리** : 리스트가 128,816B로 행렬의 약 3.2배이다. 간선 하나에 행렬은 8B(int 2칸), 리스트는 32B(노드 2개)가 든다. 두 방식의 메모리는 간선 약 1,225개(밀도 약 25%)에서 같아진다.
- **삽입·삭제·연결 여부** : 행렬은 여전히 1회, 리스트는 약 50~80회로 늘었다. 긴 리스트를 차례로 탐색해야 하기 때문이다.
- **인접 정점** : 리스트 80회, 행렬 100회로 차이가 거의 없다. 행렬의 100칸 중 80칸이 실제 이웃이라 낭비가 적다.
- **결론** : 인접 행렬이 유리하다.

## 어떤 표현을 언제 쓸까

| 상황 | 적합한 표현 | 이유 |
|---|---|---|
| 간선이 적은 희소 그래프 | 인접 리스트 | 메모리가 V + E에 비례해 공간 낭비가 없다 |
| 정점 수가 매우 많은 그래프 | 인접 리스트 | 행렬은 V² 공간이 필요하다 |
| 이웃을 순회하는 알고리즘 (BFS, DFS, 다익스트라) | 인접 리스트 | 실제 이웃만 확인한다 |
| 간선이 많은 밀집 그래프 | 인접 행렬 | 메모리가 더 작고 모든 연산이 빠르다 |
| 간선 확인·삽입·삭제가 잦은 경우 | 인접 행렬 | 항상 1회로 끝난다 |

정점 수는 같아도 간선 수가 100에서 4,000으로 늘자 메모리의 우위가 뒤집혔다. 따라서 표현 방식은 **그래프의 밀도와 주로 쓰는 연산**을 기준으로 골라야 한다.
